# 🎓 Rabbit AI
### IEEE GenAI Build — Campus Information Assistant

<p>Rabbit AI is an advanced, AI-powered campus information assistant designed to provide students, faculty, and visitors with accurate, real-time answers based on institutional documents.</p>

</div>

---

## 🌟 Overview

Rabbit AI bridges the gap between campus resources and users by processing local documentation—such as course catalogs, academic calendars, student handbooks, and faculty directories—to deliver precise, context-aware responses. 

Designed with strict zero-hallucination guardrails, the assistant ensures that all answers are explicitly grounded in the provided document repository, preventing outside assumptions on campus-specific facts.

---

## ✨ Key Capabilities

* **Document Grounding & PDF Parsing:** Automatically ingests and extracts text across multiple campus PDF files to build a comprehensive knowledge base.
* **Natural Conversational Flow:** Handles natural social pleasantries (greetings, thank-yous, and farewells) fluidly while maintaining strict verification for factual queries.
* **Multi-Turn Context:** Remembers recent chat history to allow follow-up questions and smooth conversational depth.
* **Dual-Modality Output:** Combines clear text-based explanations (formatted with headings and bullet points) with built-in text-to-speech audio playback for an accessible user experience.
